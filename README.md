# Market Timeline Persuasion

## Brand Archetypes, Design, and Methods of Persuasion

This project explores the connection between **brand archetypes, methods of persuasion, modernism, postmodernism, and design styles**. Our group worked together to research these topics and organize them into Markdown pages with examples, imagery, and references.

## Project Guidelines

- Group members follow the project template when creating Markdown files.
- Each major topic is organized into its own Markdown file.
- Images and references are included when needed to support the research.
- The project is divided among team members, with members contributing to different areas of the guide.
